# Welcome to the moodleLA-App

The moodleLA app enables you to perform your own learning analytics using Moodle data. It provides functions to download and pseudonymise data from Moodle logs and forums. You can also merge and pseudonymise additional data, allowing you to match this with data from your Moodle learning management system.

Begin with a project-specific configuration, as pseudonymisation is only as secure as the unique pepper for that project.

This page will contain a detailed introduction to using the program and its various functions. Currently, it only includes a short list of available functions.

- Course Userlist: Retrieve a pseudonymised list of all users with the learner role in Moodle.
- Moodle Logdata: Use this function to download log data from all users with the learner role in a Moodle course.
- Moodle Forum Data: Download and pseudonymise all forum messages from a Moodle course.
- Match & Pseudonymise Data: Upload existing data, such as Moodle reports or survey data, and match it with users in a Moodle course.
- Pseudonymise Data: Upload existing data and select the variables you want to pseudonymise. This is useful for pseudonymising exam results.
